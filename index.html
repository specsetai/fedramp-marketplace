Specset Cloud PlatformThe Specset Cloud Platform is a single multi-tenant SaaS service for construction document intelligence. It ingests customer project documents (project manuals and specifications, drawing sheets, shop drawings and submittals) and provides: automated submittal review against project specifications; UFGS and specification compliance checking; design review automation; document search and question answering across a project's documents; and asset management logic. Customers access the service through a web application; optional customer-initiated integrations connect to the customer's own Procore or Autodesk tenants. Production is hosted on Google Cloud Platform (us-west1, Assured Workloads) with supporting services on Amazon Web Services and Microsoft Azure as listed under third-party information resources.2025-01-22
